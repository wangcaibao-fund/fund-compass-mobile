# 基金罗盘 · 量化研究

面向手机的场外基金研究与交易纪律工具。在线历史净值、数据质量审计、复权收益与风险指标、可解释的定投/分批止盈规则、费用回测和同预算普通定投对照。

网站不连接交易账户、不自动交易。持仓和交易记录仅保存在使用者浏览器的 localStorage，部署内容不含个人持仓。

## 方法与限制

- 东方财富/天天基金公开历史净值为单一第三方来源，内部一致性检查不等于独立来源核验。
- 历史回测使用固定参数，以决策日已知信息生成信号，下一净值样本执行。
- 复权虚拟份额及红利再投资简化模型，费率由用户填写。短期赎回采用假设费率与 1.5% 较高者。
- 每月给策略和普通定投相同预算，现金利率为零。展示期末资产、净利润、XIRR、排除入金影响后的收益曲线回撤、费用和交易次数。
- 当前基金当前参数的样本内历史验证不证明未来收益。未模拟 QDII 特殊结算、限购、暂停申赎或所有产品特定费率。
- PWA 需要 HTTPS，可添加到主屏幕。首次联网使用后可缓存界面与最近查询的数据；离线不能取得最新净值。

静态站点，无构建步骤。入口 index.html，计算代码 quant-core.js，移动适配和离线文件位于同一目录。
